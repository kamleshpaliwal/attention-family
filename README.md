# Attention family

A learning project: one folder per attention variant, side by side, each with its own `.venv`.

| Folder | Variant | Status |
|--------|---------|--------|
| [`additive attention/`](<additive attention/README.md>) | Bahdanau-style additive attention, 12 steps | steps 1-6 done |

Run scripts from inside the variant's folder, using that folder's `.venv`. Files are never shared across variants.
