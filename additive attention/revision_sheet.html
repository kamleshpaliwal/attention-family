Step by step

1

Softmax

step01_softmax.py
What
Turns raw scores into weights that are positive and sum to 1.
Why exp
Always positive, keeps the order, and widens gaps so the best word dominates. Plain division breaks on negative scores.
Formulaw_i = e^(s_i) / sum_j e^(s_j)
Numbersscores [0.3 3.0 1.4 0.3] exp [1.35 20.09 4.06 1.35] sum 26.84 weights [0.05 0.75 0.15 0.05]
Worked
e^0.3 = 1.350    e^3.0 = 20.086
e^1.4 = 4.055    e^0.3 = 1.350
sum   = 1.350 + 20.086 + 4.055 + 1.350 = 26.841

cat weight = 20.086 / 26.841 = 0.748
sat weight =  4.055 / 26.841 = 0.151
The / today =  1.350 / 26.841 = 0.050 each
check: 0.050 + 0.748 + 0.151 + 0.050 = 1
Remember: adding the same number to every score changes nothing. Huge scores overflow, so real code subtracts the max first.

Encoder states

step03_encoder.py
What
An RNN reads the English sentence one word at a time and keeps a running memory. Each new state mixes the current word with everything read before.
Why
A word's meaning depends on its neighbours, so h2 is "cat, after The".
Formulah_t = tanh(Wx x_t + Wh h_(t-1) + b)
Terms
h_t new state after reading word t: the answer, shape (4,).
x_t vector of the current word, (4,).
h_(t-1) the memory before this word, (4,). All zeros for the first word.
Wx (4,4) weights: how each number of the word vector feeds each number of the memory.
Wh (4,4) weights: how much of the old memory is carried forward.
b (4,) constant nudge added to each number. Zeros here.
Wx x_t matrix times vector: output number i = row i of Wx dotted with x_t. Result (4,).
tanh squashes every number into the range -1 to 1, so the memory cannot blow up.
Numbersstart h = [0 0 0 0] h2 (cat) [-0.314 -0.267 0.348 0.251] H shape (4,4)
Worked

Decoder state

step04_decoder.py
What
The decoder's memory of what it has written. It is updated with the last French word.
Why
It starts from the encoder's summary (H[-1]) so it knows the source sentence, then tracks the French so far.
Formulas_t = tanh(Wy y_(t-1) + Ws s_(t-1) + b)
Terms
s_t new decoder memory after writing a word, shape (4,).
y_(t-1) vector of the French word just written, (4,). Fed back in, so the decoder knows what it said.
s_(t-1) the memory before this word, (4,). The very first one, s0, is H[-1].
Wy (4,4) weights: how the last written word changes the memory.
Ws (4,4) weights: how much old memory is carried forward.
b (4,) constant nudge, zeros here.
tanh squashes every number into -1 to 1.
Same recipe as the encoder, but with its own separate weights, fed with French words.
Numberss0 = H[-1] [-0.392 -0.461 0.182 0.682] s1 (after Le) [-0.92 -0.356 -0.295 0.787] s2 (after chat) [-0.825 0.539 -0.885 0.292]

Scoring function f(s, h)

step05_scoring.py
What
Gives every English word one number: how useful is it for the next French word, given s?
Dotf = s . h (no weights to learn, same sizes needed)
Additivef = v . tanh(W1 s + W2 h) (Bahdanau, learnable)
Shapes
W1@s (4,) + H@W2.T (4,4) broadcast, tanh, @ v gives (4,)
Numbersuntrained additive scores [-0.107 -0.198 -0.182 -0.353] -> weights [0.276 0.252 0.256 0.216]
Worked

 s1.h2 = -0.920*-0.314 + -0.356*-0.267 + -0.295*0.348 + 0.787*0.251
       =  0.289 + 0.095 - 0.102 + 0.197 = 0.479

Context vector

step06_context.py
What
One vector that blends all encoder states, each taken in proportion to its weight.
Why
It tells the decoder "the part of the sentence that matters now". Weight 0.75 keeps three quarters of that word's vector.
Formulacontext = sum_i weight_i * h_i = weights @ H
Codeweights[:, None] * H then .sum(axis=0)
Numberscontext [-0.363 -0.234 0.313 0.305] h2 cat [-0.314 -0.267 0.348 0.251] (close)
Worked
weights = [0.050 0.748 0.151 0.050]

each row of H times its weight:
 0.050 * h1 = [ 0.000 -0.006  0.002 -0.008]
 0.748 * h2 = [-0.235 -0.200  0.260  0.188]   <- biggest piece (cat)
 0.151 * h3 = [-0.109 -0.005  0.042  0.090]
 0.050 * h4 = [-0.020 -0.023  0.009  0.034]

add the four rows (column by column):
 first number : 0.000 - 0.235 - 0.109 - 0.020 = -0.363
 context      = [-0.363 -0.234  0.313  0.305]
 compare h2   = [-0.314 -0.267  0.348  0.251]
Remember: H is all four states. [:, None] makes the weights a column (4,1) so each ROW of H is scaled by its own weight. Always shape (4,), however long the sentence.

Easy-to-mix-up points

  • H vs H[-1]. H is all four encoder states (4,4). H[-1] is only the last row, used once as s0. Scoring and the context both use the full H.
  • Two kinds of "weights". Model weights (W1, W2, v, Wx, Wh, ...) are learned parameters. Attention weights are the softmax output, computed fresh at each step and never stored.
  • Softmax has no weights. It is a fixed formula. Random numbers live in the scorer's parameters, not in softmax.
  • Hard-coded scores. [0.3, 3.0, 1.4, 0.3] are stand-ins for the example. After training the scores come from the scorer. The weighted-sum code itself is the real thing.
  • What gets scaled. Weights scale the rows of H, not the scores. The scores were already used up when softmax made the weights.
  • Why PyTorch at step 10. NumPy has no automatic gradients, and training needs them to adjust every parameter.
